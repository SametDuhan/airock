Windows installer (unsigned: if Windows warns, choose More info, then Run anyway). macOS (.dmg) and Linux (.AppImage) installers are included.

- **Six more languages:** Italian, Russian, Portuguese, Polish, Persian (right-to-left) and Swahili, so SkyTrack now speaks fifteen. The website has them too.
- **A two-column language menu**, because fifteen names make a long list. On the first-run welcome screen every language button shows the flag of its country, so people who do not read English can pick their language by the flag.
- **Phone layout** (the web demo and the website): the menu is a drawer over the map, with a close button, and closes when you tap the map; the flight and airport cards slide up from the bottom; the bars, notices and dialogs fit a narrow screen. The website no longer opens zoomed out on a phone.
- The "This is a demo" bar of the web demo follows the language you chose.
