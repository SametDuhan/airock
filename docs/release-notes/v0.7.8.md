Windows installer (unsigned: if Windows warns, choose More info, then Run anyway). macOS (.dmg) and Linux (.AppImage) installers are included.

- **A cleaner menu:** every section (Data, Mode, Map, Filters, Aircraft) is its own card with a yellow bar on its title, and the Map section starts folded so the list of aircraft gets more room. The mode buttons lost their emoji and sit in a tidy grid. **Settings** and **Contact us** moved to a slim bar at the bottom. Contact us opens a short menu: report a bug, request a feature (both open a prefilled GitHub issue) or copy the app info for your report. The menu button is now a panel icon that shows whether the menu is open.
- **More filters:** flight phase (climbing, cruise, descending), emergencies only, and country (from the data, or from the registration prefix). A **+** next to a text box keeps what you typed as a chip, so one filter can hold several values (for example two airlines); **×** clears the field. The Filters title shows how many filters are on, and **Reset filters** clears them all.
- **Nicer controls:** the alert zone radius has − and + buttons (hold to repeat), the airport swap button spins, the search box has a clear button, readable text in the filter boxes, readable min / max labels, and the browser's black dropdown arrow is gone.
- **Better routes:** the route from the database is no longer shown while an aircraft is in the air but clearly not on it (far off the line, or flying away from the destination), because airlines reuse callsigns.
- New texts in all fifteen languages. Updated README (English and Turkish) and screenshot.
