Windows installer (unsigned: if Windows warns, choose More info, then Run anyway). macOS (.dmg) and Linux (.AppImage) installers are included.

- **A welcome screen on first run.** SkyTrack now opens with a short welcome in English (thanks for choosing it) and a language choice: English, Turkish, Spanish, German, French, Arabic, Chinese, Japanese or Korean. The tour that follows speaks the language you picked, and the choice is remembered. People who have already seen the tour are not asked again.
- **Aircraft photos: faster and sharper.** Each aircraft shows at most 3 photos, so the card loads quicker and flipping through is smoother. The first photo comes from planespotters.net (a fast CDN) when there is one, then sharper photos from Wikimedia Commons (up to 1920 px in the viewer), then the adsbdb photo.
- **The photo viewer opens at once and flips instantly.** It opens with the version the card already has and swaps in the big one when it is ready, keeping your zoom. The next photos are loaded ahead, and flipping no longer rebuilds the card behind it. Small photos are no longer blown up much, so they stay less blurry.
- **Fix:** an error in the viewer code could stop the app from starting. A test now checks that every script parses.
